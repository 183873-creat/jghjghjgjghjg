# سُوق — متجر إلكتروني جزائري

متجر عربي RTL يعمل عبر React وVite، مع واجهة متجاوبة، سلة مشتريات، طلبات الدفع عند الاستلام، ولوحة إدارة محمية بـFirebase Authentication وFirestore.

## التشغيل المحلي

1. ثبّت Node.js 18 أو أحدث.
2. ثبّت الحزم: `npm install`
3. انسخ `.env.example` إلى `.env` وضع بيانات تطبيق Firebase في المتغيرات `VITE_FIREBASE_*`.
4. شغّل `npm run dev`.

من دون إعدادات Firebase تظهر منتجات تجريبية للمعاينة، لكن لا تُحفظ طلبات ولا تتاح عمليات الإدارة. بيانات Firebase المستخدمة في تطبيق الويب ليست أسراراً؛ الحماية الفعلية للبيانات تعتمد على قواعد Firestore أدناه.

## إعداد Firebase

1. أنشئ مشروع Firebase، ثم تطبيق Web وفعّل **Cloud Firestore** و**Authentication > Email/Password**.
2. املأ `.env` ببيانات إعداد تطبيق الويب من إعدادات Firebase.
3. انشر قواعد قاعدة البيانات: `firebase deploy --only firestore:rules` (بعد تهيئة Firebase CLI للمشروع)، أو انسخ `firestore.rules` إلى صفحة **Firestore > Rules** في Firebase Console ثم انشرها.
4. أنشئ مستخدم المشرف من **Authentication > Users > Add user**.
5. امنح المشرف صلاحية الإدارة باستخدام Firebase Admin SDK من جهاز موثوق:

   - أنشئ مفتاح حساب خدمة للمشروع واحفظه محلياً خارج المستودع.
   - اضبط `GOOGLE_APPLICATION_CREDENTIALS` على المسار الكامل لملف المفتاح.
   - شغّل `npm run admin:set -- admin@example.com`، مع استبدال البريد ببريد المشرف.
   - سجّل خروج المشرف ثم دخولَه مجدداً حتى يتم تحديث رمز الصلاحية.

لا تضع مفتاح حساب الخدمة في `.env` الخاص بالواجهة أو في المستودع. صلاحية `admin` المخصّصة مطلوبة في قواعد Firestore للكتابة إلى المنتجات وقراءة الطلبات.

## تخزين الصور والطلبات

- أضف المنتجات من لوحة الإدارة باستخدام رابط صورة HTTPS مباشر. لا يحتاج ذلك إلى Firebase Storage.
- تحفظ الطلبات في مجموعة `orders`، وتشمل بيانات الزبون والولاية والمنتجات والمجموع وطريقة الدفع.
- تسمح القواعد بإنشاء الطلب من الواجهة العامة، لكنها تمنع قراءته أو تغييره أو حذفه إلا للمشرف. راجع حدود مكافحة الإساءة وإجراءات التحقق من الطلبات قبل إطلاق المتجر على نطاق واسع.

## الأوامر

- `npm run dev` — خادم التطوير
- `npm run build` — بناء نسخة الإنتاج داخل `dist`
- `npm run preview` — معاينة نسخة الإنتاج
- `npm run admin:set -- <email>` — تعيين مطالبة المشرف باستخدام بيانات اعتماد Admin SDK المحلية
